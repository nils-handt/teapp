### Pixel and declaration evidence

- Exact focused recapture hashes match the existing artifacts: the production web image is unchanged and pixel-identical to its reference; the API 36 image is repeatable.
- Repository normalization and Pixelmatch at threshold 0.1 produce 13,348 of 280,713 changed pixels (4.755%). With antialiasing included the count is 23,367 (8.324%); Pixelmatch classifies 10,019 threshold-different pixels as antialiasing.
- Every non-AA changed pixel is foreground: 122 in header glyphs/icons, 12,744 in list text/chevrons, and 482 in tab icons/labels. Broad panel fills, card fill, outer decoration, and tab fill have no threshold-exceeding pixels.
- The six visible rows preserve the same text, line counts, word breaks, colors, borders, radii, shadows, icons, spacing declarations, and Ionic variables. Remaining color-count differences are differing glyph coverage after Android physical pixels are resampled, not token drift.
- Source order differs because Ionic injects component CSS at different times, but the winning qualified app declarations and the final computed styles match. No evidence-backed shared UI change remains for this state; adding a fixed fixture-specific row height or an Android override would violate the parity strategy.
